# Whale TV Executive Workspace

Whale TV 品牌视觉版 · 纯前端交互演示
包含最新收入趋势：具体金额、日期、增长率和每日明细。

## 本地打开
解压后，双击 index.html，用 Chrome、Edge 或 Safari 打开即可。
无需安装依赖、构建项目或配置 API 密钥。
HTML 中包含全部 CSS、JavaScript、嵌入式品牌图片和模拟数据。

## 上传到 GitHub
将解压后的 index.html、README.md 和 .nojekyll 上传到仓库根目录。
不要仅上传 ZIP：ZIP 用于下载与传输，网页托管需要解压后的文件。
如果仓库已有同名文件，请先确认是否替换。
上传代码不等于自动发布网站，在线访问仍需配置静态网站托管。

## 文件说明
- index.html：完整演示源代码，可用 VS Code 编辑。
- README.md：使用说明。
- .nojekyll：静态托管标记文件。

## 演示边界
所有经营数据、人员、合作伙伴及情报均为模拟信息。
未连接 Whale TV 内部系统；没有后端、数据库或生产级鉴权。
任务和批注仅保存在当前浏览器 localStorage，换电脑不会同步。
角色切换仅模拟权限，不用于保护真实业务数据。
Whale TV 品牌素材来源于用户提供的参考图，发布范围由使用者确认。
